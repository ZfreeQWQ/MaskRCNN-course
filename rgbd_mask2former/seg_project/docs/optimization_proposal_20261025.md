**RGB-D 小目标实例分割优化建议（2026-10-25）**

建议以当前 D（Mask2Former R50 + 几何深度融合）为基线，依次验证候选保留、分辨率、实例细化与训练稳定性。主算法方向是“全图实例查询 + 深度引导的局部高分辨率细化”；新增训练方法优先考虑 MP-Former。下列新方法均尚未验证收益，不把论文在其他数据集上的增益视为本项目的预期分数。

本次完成了论文检索、源码核查和 D 的全量 val 候选覆盖诊断；没有重训或改动模型推理行为。诊断脚本是 `tools/diagnose_d_val_recall.py`，结果为 `reports/analysis/d_val_candidate_coverage_20261025.json`。关键实现文件的本地与服务器 SHA-256 一致。

**已有证据**

D 的完整 val Mask APs 为 0.379688、Mask AP 为 0.737941。把分数阈值从 0.5 降到 0 后，APs 由 0.374168 提高到 0.379688；这一改进不能解释或消除全部线上差距。当前五组都是 6 epoch，D 最好；DS、DSH 的 APs 分别为 0.287262、0.302612。

本次对 2,584 张 val 图、73,421 个非 crowd GT 和 258,400 个现有候选逐图计算 mask IoU。下表是“每个 GT 是否存在任何候选达到指定 IoU”的覆盖比例，**不是 COCO AP 或 AR**，没有一对一匹配，也没有考虑排序。它衡量现有候选的定位潜力。

| GT 分组 | GT 数 | 存在 IoU≥0.5 候选 | 存在 IoU≥0.75 候选 | 存在 IoU≥0.9 候选 |
|---|---:|---:|---:|---:|
| 全部小目标，面积 ≤1024 px² | 10,999 | 75.60% | 44.34% | 12.78% |
| 极小目标，面积 ≤256 px² | 2,185 | 38.67% | 15.47% | 1.46% |
| 面积 256–1024 px² | 8,814 | 84.75% | 51.50% | 15.59% |
| 小目标，mask/bbox 面积比 <0.25 | 4,023 | 61.55% | 17.35% | 0.82% |

极小目标中 61.33% 缺少 IoU≥0.5 的候选，需要提高召回；低填充率小目标即使找到候选，也很少达到高 IoU，需要改善细丝、残片和边界。调分数无法创造缺失的候选或修复掩码几何。

训练集已有形态统计显示，小目标约 60.7% 含多个连通碎片，mask/bbox 面积比中位数约 0.30。这个结论来自训练集统计，足以支持残片感知设计；后续不依赖 test 标注或其切片统计选择方案。

**先处理三处实现与实验解释问题**

1. **DSH 的高分辨率头没有接入推理。** `rgbd_seg/m2f/model.py:95` 在 eval 时直接返回原版 `MaskFormer.forward`；`hires_mask.py:73` 的 `refine_top_k_masks` 在实际训练/推理入口中没有调用，只有定义与独立测试。高分辨率损失确实能改变训练梯度，但训练好的细化头没有直接参与最终 mask 输出。因此已有 DSH 分数不是“完整高分辨率推理”的消融结果。修复时要在保留粗 mask logits 的阶段接入，复用训练时的图像标准化，并在细化后重新算 mask score。先用小批量验证调用次数、输出变化与分块一致性，再做完整 val。

2. **候选先按分类分数截断，再计算 mask 分数。** `third_party/Mask2Former/mask2former/maskformer_model.py:352` 从 200 个 query 先取分类分数前 100；第 378 行才乘以 mask 内平均概率。这是当前官方实现的顺序，不是已证实的 bug，但可能损失本任务中的小目标。首轮比较全部 200 个候选计算最终分数后再选 100；最终提交上限仍然是 100。已有 JSON 只有旧前 100，必须重新推理才能评估这一步。

3. **DS 同时改变匹配采样和损失采样，缺少拆分实验。** Matcher 的额外 256 点是每图共享总量，由所有小目标分摊（`matcher.py:52`），不是每个小目标 256 点。Loss 替换最后 30% 的采样点（`small_object_sampling.py:110`）；原 PointRend 采样先拼接 75% 不确定点，再拼接 25% 全图随机点，因此全图随机部分会被全部替换，还会替换一部分不确定点。这可能改变背景监督和 Dice 的采样分布，但尚不能断言它是 DS 退步的唯一原因。

**优先级与具体方案**

| 顺序 | 实验 | 是否重训 | 要回答的问题 |
|---|---|---|---|
| 1 | D：200 个候选按最终 mask 分数排序后取 100 | 否，重新推理 | 分类分数预截断是否损失小目标？ |
| 2 | D：1024 / 1280 / 1536 单尺度推理 | 否 | 提高有效分辨率能否找回极小目标、提高高 IoU 覆盖？ |
| 3 | D：全图 + 4 个 640×640 重叠块，块放大到 1024 | 否，先作诊断 | 局部放大能否改善单纯全图放大未解决的漏检？ |
| 4 | DSH：接入已有细化头后重新评估 | 否，先复用现有权重 | 现有细化头是否具有实际推理价值？ |
| 5 | D + 深度引导局部细化，保持原 matcher/loss | 是，可先冻结主干训练细化头 | 独立的边界细化能否改善 APs75/高 IoU 覆盖？ |
| 6 | D + MP-Former 训练 | 是 | query 的训练稳定性和利用率是否限制极小目标召回？ |
| 7 | D + GT 前景/边界辅助采样；匹配与损失分别消融 | 是 | 正样本监督不足是否是问题，而非总点数不足？ |

先完成 1–4，依据实际收益再选训练实验。每个对照只变一个因素，筛选后再组合。阈值统一为 0，所有最终输出最多 100 个实例。

**方案 A：保留全图上下文的局部放大**

先做 1280、1536 单尺度对照，再尝试全图加四角 640×640 裁剪，裁剪起点为 0/384，邻块重叠 256 像素，每块放大到 1024。640→1024 是 1.6 倍，处于原训练放大范围的上界，但仍需验证裁剪分布影响。五次前向会增加推理成本，必须记录 ms/图和峰值显存。

RGB 与几何深度通道同步裁剪；高度、法向等先在完整原图上计算再裁剪，避免直接在裁剪坐标中使用原相机内参导致几何错位。映射回 1024×1024 后做实例匹配与 mask 去重。对本任务不能简单使用 bbox NMS：不同实例的框可能高度重叠，同一实例也可能是不连通的残片。保留完整图预测作为上下文，不把连通分量自动拆成不同实例，也不仅因深度接近就合并对象。

论文依据是 [SAHI, ICIP 2022](https://arxiv.org/abs/2202.06934) 的切片推理与微调思想。原论文主要验证的是检测框任务；上述 RGB-D mask 融合与残片处理是本项目需要验证的改造，不能直接套用其检测 AP 增益。

**方案 B：深度引导的实例局部高分辨率细化（建议作为主算法改进）**

保留 D 的全图 query 和粗 mask 身份，利用共享的高分辨率 RGB/深度特征，在每个预测实例的上下文区域内进行细化。输入包括粗 mask logits、RGB 细粒度特征、几何深度特征；必要时加入 query 特征，使相邻同类元器件仍保持实例区分。输出是 mask residual，再映射回原图。

第一版使用带上下文的实例框内 128×128 或 256×256 特征，或者只在不确定点上预测残差；按实例分块处理。不要再为每个实例复制整张 512×512、64 通道特征图。需要同时保留一个实例的多个残片，并设置粗细预测一致性，降低跨实例吸附风险。

训练先冻结 D，使用预测框与适量扰动框训练细化头，以减少训练依赖 GT 框而推理只见预测框的差异；之后再小学习率联合微调。保持原 matcher 和原采样规则，单独确认细化收益，再加入残片采样。推理使用预测的面积/不确定性决定细化范围，不能使用 GT 小目标标签。

[PointRend, CVPR 2020](https://arxiv.org/abs/1912.08193) 提供按不确定性选择点并迭代细化的思路；[RefineMask, CVPR 2021](https://arxiv.org/abs/2104.08569) 提供逐级融合细粒度特征的思路。它们支持“把细节计算集中到需要的部位”，但上述深度融合和残片保持策略属于待验证的项目设计。

细化只能改善已有候选，不能解决全部漏检。因此它应与方案 A 或提高 query 学习质量的方法配合。当前低填充率小目标 IoU≥0.75 覆盖仅 17.35%，是细化实验最应该观察的切片。

**方案 C：MP-Former 训练，优先于继续叠加当前 S 模块**

[MP-Former, CVPR 2023](https://arxiv.org/abs/2303.07336) 针对 Mask2Former 不同 decoder 层之间预测与优化目标不一致的问题，使用 GT mask 引导的训练方式；论文提出加噪 mask 重建，推理阶段不增加该训练分支计算。它与当前主框架直接相关，比同时更换 backbone、decoder 和 RGB-D 融合更容易分析收益。[官方实现](https://github.com/IDEA-Research/MP-Former) 已提供，README 也包含无噪声 all-layer 训练配置，实际移植时应先复现一种明确设置，而非混合多种 denoising 变体。

保留 D 的深度融合和标准 mask 损失；单独增加训练用 mask-piloted 分支，保证普通 query 与 GT 引导分支的 attention 隔离正确。小目标噪声要检查是否把几像素残片彻底抹掉。先做正常 query 输出无 GT 泄漏、损失有限、DDP 梯度与推理路径检查，再做匹配预算的训练。潜在优势是提高训练效率和候选质量；本项目 APs 收益目前未知。

**方案 D：GT 前景与边界的辅助监督**

保留原 12,544 点及原 matcher，额外对每个小 GT 从真实前景像素中心、边界附近和外部背景采样少量点，作为权重较小的独立辅助 loss。对于不连通碎片，分配最小采样名额，避免只看到最大连通块。先比较辅助权重 0 / 0.1 / 0.3；总量与损失归一化明确，不把局部重采样后的 Dice 当成全图均匀采样的无偏估计。

先只改 loss；确认有效后再单独改 matcher。记录每个 GT 实际采到的前景点数、匹配变化率、small 与 non-small 损失梯度规模。这是针对当前代码和训练集形态的假设，不宣称为论文已证明的通用最优配方。

**方案 E：学会预测 mask 质量，再做排序**

[Mask Scoring R-CNN, CVPR 2019](https://arxiv.org/abs/1903.00241) 使用预测的 mask IoU 校正分类置信度与分割质量的不一致。当前 Mask2Former 已经有“分类概率 × mask 内平均概率”，但平均概率不等同于真实 IoU。

在候选数量与几何质量改善后，可用 train 预测训练轻量质量头，输入 query/实例特征及 mask 特征，预测 IoU 或多个 IoU 阈值下的质量，再与分类分数结合排序。先做 train 内留出或 out-of-fold 数据，避免仅用训练集过拟合预测训练校准器；val 只选方案。不要只凭预测面积给小 mask 加分，因为碎片假阳性也会被一并抬高。

**其他候选与取舍**

- [Simple Copy-Paste, CVPR 2021](https://arxiv.org/abs/2012.07177)：可借鉴实例级数据增强，但 RGB-D 不能只贴 RGB。若做遮挡增强，须同步更新 RGB、深度和可见 mask，重新计算边界相关几何编码。更低风险的第一步是按 train 的小目标数量、可见面积与碎片难度做适度场景重采样，同时保留普通场景比例。
- [Mask DINO, CVPR 2023](https://arxiv.org/abs/2206.02777)：检测与分割联合训练是值得保留的替代基线，尤其适合验证定位/候选学习瓶颈。但更换模型需要迁移深度融合、检查 checkpoint 与 CoreX 算子兼容性，并重新建立公平训练对照，因此排在上述直接利用现有 D 权重的实验之后。
- 更大 backbone、12 epoch、TTA 可作为独立基线提升，不与算法改动混在同一对照中。D 和改进模型必须用相同训练预算；现有 D 的最佳点在 6 epoch 末尾，因此仍值得建立更长训练的对照。

**实验判据**

首先用固定、按场景分层的小规模 val 子集排除无效/显存不可行方案，再对候选跑完整 2,584 张 val。最终比较 Mask APs、AP、AP50/AP75、ARs、≤256 px² 与低填充率切片，以及 ms/图和峰值显存。新候选覆盖诊断只作解释，不替代官方 COCO 主指标。

相邻视角属于同一场景，置信区间或重采样按 scene 分组，避免把近似视图视为独立样本。小幅收益做重复推理确认；主要训练方案至少检查不同随机种子的稳定性。训练开销较大的改动可暂以 APs 增加 0.005 且整体 AP 下降不超过 0.003 作为推进参考，而不是宣称已能获得该增益。

后续模型与超参只依据 train/val 选择，测试集用于最终生成提交。服务器沿用现有 PyTorch/CoreX 环境及 `run.sh`，新增模块先检查现有依赖与算子，不通过升级底层环境实现兼容。

建议首先实施“200 候选重新排序 + 1280/1536 单尺度对照 + 接通 DSH 推理细化”三项低成本实验。主训练路线优先比较 **D + 局部 RGB-D 细化** 与 **D + MP-Former**，再决定是否组合。
