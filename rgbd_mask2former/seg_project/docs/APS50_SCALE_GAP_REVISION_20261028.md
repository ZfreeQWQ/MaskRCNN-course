# 以隐藏test APs>50为目标的实验优先级修订（2026-10-28）

用户指出test往往比val低约14点。按此经验差距估算，当前val56.096仅对应test约42.1；
test50大致要求val64或显著缩小泛化差距。它是规划估算，不是对新模型隐藏test分数的测量，也不是恒定的换算规律。
原val55.367与用户反馈的Kaggle约41仍为唯一已确认的基线配对；尚不能将val正收益直接等量外推到线上。

## 为什么不以0.7点微调收益作为主要路线

四轮实验的裁剪组训练6轮后val APs56.096，相对父模型+0.729；普通局部监督组54.804、组合组54.699，暂未显示正收益。
同预算控制组6轮尚在训练，所以裁剪组的收益还不能全部归因于裁剪本身。

对完整val预测按COCO一对一匹配重算，面积≤256像素的2185个小目标：

| 指标 | 父模型 | 裁剪6轮 |
|---|---:|---:|
| IoU≥0.50召回 | 65.172% | 66.041% |
| IoU≥0.75召回 | 38.764% | 39.405% |
| IoU≥0.90召回 | 10.709% | 10.526% |

极小目标仍缺有效候选和精确mask，现有训练配方对这一组改善很小。
普通局部监督6轮的同组IoU≥0.75召回仅33.638%，因此不把继续增加这项loss权重作为主线。

## 已实现的新实验

使用同预算6轮中表现最好的合格完整val checkpoint，固定权重，检验分辨率和覆盖瓶颈：

1. 对照：原全图1536、mask-first、最多100实例，直接复用对应checkpoint的完整val预测。
2. 全图2048：保持同一权重和原图坐标评估，隔离全图分辨率影响。
3. 全图1536＋4个640×640重叠局部视图，各视图放大到1536；1024原图上的局部视图起点为0/384，重叠256。
   检验局部预测置信度乘0.9或1.0两个预先规定的版本。

深度几何在原图计算一次，再和RGB一起裁剪；RGB沿用双线性缩放，几何沿用最近邻。
完整视图输入张量必须与已有mapper完全相同，四卡工程检查另需复现原完整视图的mask和分数。
局部mask恢复到原图坐标；仅补充预测面积≤4096的局部候选，不依赖GT判断推理目标大小。
距离内部裁剪边缘3像素内出现前景的局部候选被过滤，避免把明显截断的目标当作完整实例。
跨视图按mask IoU≥0.55或交集/较小mask面积≥0.85去重，保留更高分实例，最终最多100个。
同视图不做额外抑制；不因bbox重叠合并，也不拆散一个query预测的多个可见残片。
这些是本项目的实例分割适配，不是SAHI检测结果的复现。

方案依据：[SAHI原论文](https://arxiv.org/abs/2202.06934)及[作者的切片推理文档](https://obss.github.io/sahi/guides/sliced-inference/)。
论文结果来自其他检测任务，不能据此预报本项目APs收益。

## 设计、确认与资源安排

- CPU已有10项检查通过，包括真实RGB-D mapper输入完全一致、原图mask坐标/RLE、裁剪覆盖、内部边缘、重复预测与独立实例保留。
- 当前四卡控制组的训练进程继续运行。只切换队列协调器，不停止训练worker，不覆盖任何旧模型或配置。
- 完成控制组6轮后，先进行四卡4图工程检查；这4图只检查实现，不用于挑权重。
- 再用固定SHA256规则选出的64个val场景（约256图）的所有视角比较3个版本。选择过程只读val，不读test标注。
- 设计集APs至少比同权重1536高1.0点、整体AP不降超过0.3点，才对胜出版本做完整2584图验证。
- 完整val至少+1.0 APs，且与设计场景不重叠的剩余场景至少+0.8 APs、整体AP满足同样限制，才生成候选test CSV。
- 设计集未达门槛或完整验证未确认，记录失败证据后回到既定最佳算法/同预算对照的12/18/24轮实验；不自动重跑失败输出目录。
- 若确认收益，使用同一推理函数生成2112行test CSV，验证所有RLE、图像覆盖和SHA256后同步到本地deliverables；由Kaggle检验真实分数。

这项实验检验能否突破有效像素/候选覆盖瓶颈，并不预设它能补足约8点差距。
若有效放大仍无法改善极小目标，高分辨率局部mask头、训练分布与跨型号泛化才有更明确的实施依据；不能用继续多跑几轮代替诊断。
