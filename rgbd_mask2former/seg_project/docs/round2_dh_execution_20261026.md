# 第二轮首批：D+H 独立消融与普通 D 对照

## 固定基线与目的

固定初始权重：`experiments/mask2former/d_continue6_results_20261026/best_segm_APs.pth`。
该权重在 2,584 张完整 val 上的 mask-first APs 为 **52.9162213**，AP 为 **81.6031070**（本文件分数均使用 0–100 尺度）。

本批检验已有半分辨率细化 H 在关闭 S 后是否有价值，同时测量相同额外训练预算的普通 D。
这属于当前最佳模型的权重初始化微调：AdamW 与学习率日程重新开始；不是原训练状态的无缝续训，也不是从头训练对照。

## 两组协议

| 设置 | 普通 D | D+H |
|---|---|---|
| 初始 D 权重 | 同一份冻结最佳权重 | 相同；H 新增参数初始化 |
| S 匹配/采样 | 关闭 | 关闭 |
| H | 关闭 | 开启 RGB-D 半分辨率头 |
| 全局 batch / GPU | 8 / 4 | 8 / 4 |
| 额外更新 | 3608，2 epoch | 3608，2 epoch |
| 主网络初始 LR | 1e-5，backbone 乘 0.1 | 相同 |
| 新增 H 初始 LR | 无 | 1e-4 |
| 日程 | warmup 100；2886 / 3355 降 LR | 相同 |
| 训练 / 验证尺寸 | 1024 / 1536 | 相同 |
| 完整 val | 每 1804 步及结束 | 相同 |
| seed | 20261020 | 相同 |
| 每步 H 训练实例上限 | 无 | 16，按现有随机抽样规则 |

现有数据增强、标准 Hungarian matcher 和标准点采样均保留。由于新增头初始化会消耗 RNG，相同 seed 不代表两组每一个随机增强逐项完全相同；本批为单种子工程筛选，不能代替多种子统计结论。

## 验证与选优修正

新增 `round2_inference.py` 与 `round2_trainer.py`，保留原有训练器和已审计推理源码。

1. 同一次骨干/decoder 前向恢复全部 200 个 query 的原图 logits。
2. 按分类分数乘掩码质量选出 100 个 query；两条分支保留相同的 query 身份。
3. H 只细化预测原图面积处于 `(0,1024]` 的入选掩码；面积门限不读取 GT。
4. 细化后重新计算这些实例的掩码质量分数，保留每图最多 100 个候选、阈值 0。
5. D+H 同时报告 `segm`（细化）和 `coarse_segm`（未细化），按 `segm/APs`、`segm/AP` 次级选优。
6. 普通 D 采用相同 mask-first 推理与完整 val 选择。

现有 H 包含 coarse→半分辨率→原图的额外双线性插值，因此即使最后卷积为零，refined 与直接 coarse 恢复也不保证逐像素一致。这是本次对现有 H 实现的检验，并非新增 ROI 或 query 条件化细化算法。

`inference/coco_instances_results.json` 和 `best_val_predictions.json` 对应实际选择用的分支。另存 `inference_coarse/`、每图细化计数、改变像素数和头部参数范数，检查 H 确实参与验证。所有预测先保存在原图坐标再做 COCO mask 评估。

## 已完成的工程检查

- 4 项确定性协议测试：最多 100 候选、预测面积门限、分块一致性、无标注依赖，以及验证后恢复训练模式。
- 24 个 H 实例上限的四卡 30 步训练和 16 图双分支验证成功。显存接近 31GB，正式配置降低上限至 16。
- 独立加载该短训权重，在 3 张真实图像逐项比对：新 coarse 分支与已建立的 mask-first 输出一致；legacy 分支与原模型推理一致。
- 11 个 H 参数组的学习率检查通过，头部残差范数非零，真实图像有掩码像素变化。
- 正式 16 实例上限另做四卡 60 步训练、16 图成对验证与权重审计，结果见 smoke 目录与自动管理器的启动检查。

最初一次短训启动因多余的 `--opts` 命令行参数在训练前退出；日志保留。修正后成功的短训分别保存在 `round2_dh_smoke_v2_20261026` 和 `round2_dh_smoke_v3_20261026`，互不覆盖。

短训子集按数据集 ID 截取，仅验证工程正确性，禁止用其 APs 推断完整验证效果或选择最终模型。
